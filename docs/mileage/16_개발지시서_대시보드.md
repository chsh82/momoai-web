# 개발 지시서 — 모모 마일리지 대시보드

마이페이지의 마일리지 영역을 대시보드 형태로 개편한다.

> 이전 5단계 지시서의 C 항목을 현재 상태(실명 전환, 커뮤니티 개방 완료)에 맞춰 갱신한 것이다.

--- 프롬프트 시작 ---

마이페이지의 마일리지 영역을 대시보드로 개편한다. 데이터 로직은 바꾸지 않고 화면 구성만 손댄다.

## 원칙

- 서비스 계층(`mileage_view_service`, `mileage_service`, `badge_service`)만 호출한다. 라우트나 템플릿에서 `point_events`를 직접 쿼리하지 않는다
- 기존 Tailwind 클래스와 Jinja 구조를 따른다. 새 CSS 프레임워크나 JS 라이브러리를 추가하지 않는다
- 모바일에서 먼저 보기 좋게 만든다. 학생 대부분이 휴대폰으로 접속한다
- 닉네임과 공개 설정 UI는 이미 제거됐다. 되살리지 마라

## 1. 명칭

학생·학부모에게 보이는 모든 화면에서 **「모모 마일리지」**로 표기한다. 관리자 화면과 코드 내부 명칭은 그대로 둔다.

## 2. 요약 카드 (마이페이지 상단)

한눈에 들어오는 카드 하나로 묶는다.

- **누적 점수**와 현재 등급, 등급 진행도(별 4개)
- **다음 등급까지 남은 점수**
- **이번 달 점수**와 잠정 순위
- 확정 대기 점수가 있으면 "확정 대기 N점 포함"을 작게 병기

등급 진행도는 기존 진행바 패턴을 재사용한다.

## 3. 활동 요약

이번 달 기준으로 무엇을 해서 점수를 얻었는지 보여준다. 점수 총액만 보여주면 학생이 다음에 뭘 해야 할지 알 수 없다.

- 리라이팅 N편 / 기본과제글 N편 / 퀴즈 N회 / 질문 N건 / 댓글 N건 / 출석 N주
- 각 항목 옆에 해당 활동으로 얻은 점수를 함께 표시
- 활동이 0건인 항목도 회색으로 보여준다. 안 한 것이 보여야 동기가 생긴다

## 4. 뱃지 표시 방식 변경

현재는 3×3 수집판 전체가 마이페이지에 펼쳐져 있다. 이를 요약 형태로 바꾼다.

- 마이페이지에는 **획득한 뱃지만** 가로로 나열한다
- 옆에 "10개 중 N개"를 표시한다
- 획득한 뱃지가 없으면 "아직 획득한 뱃지가 없어요"와 함께 **가장 얻기 쉬운 미획득 뱃지 하나**를 조건과 함께 안내한다
- 이 영역 전체를 클릭하면 **전체 뱃지 화면**으로 이동한다

전체 뱃지 화면(신규)

- 3×3 수집판과 최종 뱃지 「책장의 주인」
- 미획득 뱃지는 흐린 실루엣 + 달성 조건 + 진행도(예: 받은 좋아요 18/30)
- 획득한 뱃지는 획득 일자를 함께 표시
- 반복 획득 가능한 뱃지는 획득 횟수 표시 (예: 우수답안 ×3)

## 5. 적립 내역

- 대시보드에는 **최근 5건**만 표시하고 "전체 보기" 링크를 둔다
- 전체 보기 화면에서 기존 페이징을 유지한다
- 각 줄에 날짜·활동명·점수·상태(확정/대기/취소)를 표시하고, 취소 건은 사유를 함께 보여준다

## 6. 학부모 화면

학부모의 자녀 마일리지 화면도 동일한 대시보드 구조를 적용한다. `mileage_view_service`를 공용으로 사용해 두 화면이 갈라지지 않게 한다.

자녀가 여러 명이면 기존 자녀 선택 구조를 그대로 따른다.

## 7. 확인

- 0점·뱃지 0개 상태에서 화면이 비어 보이지 않고 안내가 나오는가
- 뱃지 영역을 클릭하면 전체 화면으로 이동하는가
- 전체 화면에서 미획득 뱃지의 조건과 진행도가 보이는가
- 확정 대기 점수가 확정 점수와 구분되어 표시되는가
- 취소된 적립 건에 사유가 보이는가
- 학부모 화면이 학생 화면과 같은 정보를 보여주는가
- **모바일 폭 375px에서 요약 카드, 활동 요약, 뱃지 나열이 깨지지 않는가**
  (코드 구조 검토가 아니라 실제 렌더링 결과로 확인할 것)
