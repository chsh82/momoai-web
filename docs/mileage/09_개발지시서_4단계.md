# 개발 지시서 4단계 — 화면 구현

## 사용 방법

3단계까지 데이터가 정상적으로 쌓이는 것을 확인한 뒤 시작한다. 화면은 데이터가 맞은 다음에 만들어야 한다.

---

--- 프롬프트 시작 ---

마일리지 기능 4단계를 구현한다. 학생·학부모·관리자 화면을 만든다.

## 먼저 읽을 것

- `templates/macros/badges.html` — 기존 `tier_badge()` 매크로 패턴
- `app/profile/routes.py`, `app/parent_portal/`, `app/admin/routes.py` — 붙일 위치
- `app/utils/decorators.py` — 권한 데코레이터
- `docs/mileage/01_마일리지_운영정책.md` 제7조·제8조

## 공통 원칙

1. 기존 Tailwind 클래스와 Jinja 템플릿 구조를 따른다. 새로운 CSS 프레임워크나 프런트엔드 라이브러리를 추가하지 않는다.
2. 날짜 표시는 기존 `kst` 필터를 쓴다.
3. 권한 검사는 기존 데코레이터를 쓴다. 새로 만들지 않는다.
4. 화면은 **서비스 계층 함수만 호출**한다. 템플릿이나 라우트에서 `point_events`를 직접 쿼리하지 않는다.
5. 모바일에서 먼저 보기 좋게 만든다. 학생 대부분이 휴대폰으로 접속한다.

## 작업 범위

### 1. 학생 마이페이지 — `app/profile/`

기존 마이페이지에 마일리지 섹션을 추가한다.

- **현재 등급 카드**: 등급명, 별 진행도(★★☆☆), 누적 포인트, 다음 등급까지 남은 점수
- **이번 달 점수**와 잠정 순위
- **뱃지 수집판**: 3×3 그리드. 획득한 뱃지는 컬러, 미획득은 흐린 실루엣 + 달성 조건 + 진행도. 최종 뱃지(책장의 주인)는 판 위에 별도 표시
- **적립 내역**: 최근 20건. 날짜, 활동명, 점수, 상태(확정/대기/취소). 더보기 페이징
- 대기 중인 포인트는 "확정 대기"로 구분해 표시한다. 나중에 사라질 수 있는 점수를 확정된 것처럼 보여주면 안 된다

뱃지 아이콘 파일이 아직 없으면 임시로 이모지나 단색 SVG를 쓰고, 경로만 `badges.icon_path`에서 읽도록 구조를 잡는다.

### 2. 월간 랭킹 페이지 — 신규 블루프린트 또는 `student_portal` 하위

- 학년(레벨) 그룹별 탭
- 이번 달 잠정 순위와 지난달 확정 순위를 구분해 표시. **잠정 순위에는 "집계 중" 표시를 반드시 넣는다**
- 표시 정보: 순위, 닉네임, 학년, 점수, 보유 뱃지. **실명·학교명·연락처는 절대 표시하지 않는다**
- 공개 미동의 학생은 익명으로 표시 (예: "○○ 학년 학습자")
- 본인의 순위는 표에서 강조하고, 상위권 밖이면 표 하단에 본인 순위를 따로 보여준다
- 지난 12개월치를 월별로 조회할 수 있게 한다

기존 「명예의 전당」 게시판과 **다른 메뉴**로 만든다. 두 기능을 합치지 말 것.

### 3. 공개 동의 화면

`03_공개_및_저작물_활용_동의서.md`의 A·B·C 항목을 **각각 별도 체크박스**로 받는다.

- 마이페이지 안에 "공개 설정" 영역으로 배치
- 항목별로 켜고 끌 수 있으며, 변경 시 `mileage_consents`에 새 행을 추가한다 (기존 행 수정 금지)
- 만 14세 미만 학생은 본인이 아니라 **연결된 학부모 계정에서만** 동의할 수 있게 한다
- 동의하지 않아도 불이익이 없다는 안내 문구를 화면에 표시한다

### 4. 학부모 화면 — `app/parent_portal/`

자녀의 누적 포인트, 등급, 뱃지 수집판, 적립 내역을 조회할 수 있게 한다. 자녀가 여러 명이면 선택 탭을 둔다.

- 열람 범위는 `ParentStudent.permission_level`을 따른다
- 다른 학생의 점수는 공개된 랭킹 범위에서만 볼 수 있다
- 자녀의 공개 동의 설정을 학부모가 변경할 수 있게 한다

### 5. 관리자·강사 화면 — `app/admin/`, `app/teacher/`

**우수답안·우수질문 선정**
- 강사가 학생 답안이나 질문에서 선정 버튼을 누르면 EX01 또는 QS02가 적립된다
- 화면에 **이번 주 남은 선정 횟수**를 표시한다 (강사당 주 3명)
- 상한에 도달하면 버튼을 비활성화하고 사유를 안내한다

**포인트 수동 지급·회수**
- EV01 재량 지급 (월 500점 상한)
- 부정 적립 회수. 사유 입력을 필수로 한다
- 권한: 매니저 이상. `requires_permission_level` 사용

**뱃지 수동 수여**
- BG09 모의고사 장원 수여용. 회차 정보를 메모로 입력받는다

**모니터링 화면**
- 강사별·학생별 우수답안 선정 현황 (편중 확인용)
- 최근 적립 내역과 대기 중인 포인트 건수
- 학생별 포인트 상세 조회와 취소 기능

## 확인 방법

1. 학생 계정으로 로그인해 마이페이지·랭킹·공개 설정이 정상 표시되는가
2. 학부모 계정으로 자녀 정보만 보이는가, 다른 학생 정보가 새지 않는가
3. 공개 미동의 학생이 랭킹에서 익명으로 표시되는가
4. 강사 계정에서 주 3명 상한이 실제로 막히는가
5. 휴대폰 화면 폭에서 수집판과 랭킹표가 깨지지 않는가

## 하지 말 것

- 라우트나 템플릿에서 `point_events` 직접 쿼리
- 실명·학교명·연락처를 랭킹에 노출
- 기존 명예의 전당 게시판과 통합
- 새 CSS 프레임워크나 JS 라이브러리 추가
