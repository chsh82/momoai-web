# 튜토리얼 개발 0단계 — 콘텐츠를 JSON으로 추출

너는 momoai.kr(Flask 3.1 / SQLAlchemy 2.0 / SQLite / Jinja2+Tailwind / Alpine.js) 리포에서 작업한다.
이번 단계는 **화면을 만들지 않는다.** 교재 빌더 스크립트에 흩어져 있는 글쓰기 튜토리얼 콘텐츠를,
앞으로 튜토리얼과 교재가 함께 읽을 **버전 관리되는 JSON 파일**로 옮기는 것이 전부다.

## 배경

- 이미 만들어진 교재 《문장과 생각》 초등판의 1부(원고지 14규정)가
  `build_elem.py`의 `RULES` 리스트에 파이썬 dict로 들어 있다. (별도 zip으로 전달됨. 없으면 물어봐라)
- 원고지 그림은 HTML을 직접 쓰지 않고 **문자열 한 줄 = 원고지 한 줄** 표기법으로 쓴다.
  - `(공백)` 빈 칸 · `{20}` 한 칸에 여러 글자 · `!x` 강조 칸 · `#x` 강조+부호를 칸 가운데에 잘못 놓음 · `~x` 두 줄 긋기
  - 예: `'해법은 다르!{다.}'` → 일곱 칸, 마지막 칸에 '다.'가 함께 들어가고 강조.
- 이 표기법은 건드리지 말고 문자열 그대로 JSON에 옮긴다. (렌더러가 이 문자열을 파싱한다)

## 산출물

`app/tutorial/content/elem/course1.json` 한 파일. 스키마는 아래를 **정확히** 따른다.

```json
{
  "track": "elem",
  "course": "course1",
  "title": "원고지 — 칸의 약속",
  "lede": "원고지는 어려운 규칙이 아니라 칸을 쓰는 약속이에요...",
  "lessons": [
    {
      "id": "elem-c1-l1",
      "order": 1,
      "title": "원고지 편 · 레슨 1",
      "cards": [
        {
          "no": "2",
          "star": true,
          "title": "문단이 시작되면 첫 칸을 비워요",
          "say": "새 문단을 시작할 때는 <b>첫 칸을 비우고 둘째 칸부터</b> 써요...",
          "why": "첫 칸이 비어 있으면 읽는 사람이 ...",
          "remember": "다 쓰고 나서 왼쪽 첫 칸만 훑어보세요...",
          "grids": [
            { "tone": "bad",  "n": 13, "tag": "첫 칸부터 글자를 썼어요",   "rows": ["!첫 칸부터 썼어요."] },
            { "tone": "good", "n": 13, "tag": "첫 칸을 비우고 시작했어요", "rows": ["!{ }첫 칸을 비웠어요."] }
          ],
          "tag": "관행"
        }
      ],
      "questions": [
        {
          "id": "elem-c1-l1-q1",
          "type": "choice",
          "ruleNo": "2",
          "ruleName": "문단 첫 칸",
          "q": "문단을 시작하는 바른 모습은?",
          "opts": [
            { "n": 13, "rows": ["!첫 칸부터 썼어요."] },
            { "n": 13, "rows": ["!{ }첫 칸을 비웠어요."] }
          ],
          "a": 1,
          "why": "문단이 바뀔 때마다 <b>첫 칸을 비우고 둘째 칸부터</b> 써요."
        }
      ]
    }
  ]
}
```

### 필드 규칙

- `cards[]`는 `build_elem.py`의 `RULES` 필드를 그대로 매핑한다:
  `no→no`, `star→star(없으면 false)`, `title→title`, `say→say`, `why→why`, `try_→remember`,
  그리고 `bad/bad_cap/good/good_cap/n`을 `grids` 배열로 합친다
  (bad는 `{tone:"bad", n, tag:bad_cap, rows:bad}`, good은 `{tone:"good", ...}`).
- `tag`는 규정/어법/권장/관행 중 하나. 원고지 편은 **전부 `"관행"`**으로 넣는다.
  (교재 제작 기록의 결정사항. 나중에 채점 지표 연동 시 규정·어법만 반영하기 때문에 태그가 필요하다)
- `questions[]`는 교재에 없다. **새로 만들지 말고**, 이번 단계에서는 아래 레슨 구성만 채운다(문항은 내가 준 것만 넣는다).

### 이번에 담을 레슨 (레슨 1 하나만)

레슨 1에 넣을 규정 카드 4개와 문항 4개는 아래를 그대로 쓴다. (규정 원문은 `RULES`에서 no로 찾아 옮긴다)

- 카드: no `2`(★), `5`(★), `6`, `10`(★)  ← 이 순서
- 문항 4개:
  1. `type:choice` · ruleNo `2` · "문단을 시작하는 바른 모습은?" · opts `[{n:13,rows:["!첫 칸부터 썼어요."]},{n:13,rows:["!{ }첫 칸을 비웠어요."]}]` · a `1`
  2. `type:choice` · ruleNo `5` · "앞 줄이 꽉 찼고 다음 낱말로 넘어가요. 바른 모습은?" · opts `[{n:6,rows:["환경 문제는","!{ }심각해요."]},{n:6,rows:["환경 문제는","심각해요."]}]` · a `1`
  3. `type:fill` · ruleNo `6` · "'2026년'을 원고지에 놓아 보세요." · `n:6` · `answer:["20","26","년","","",""]` · `pieces:["20","26","2","0","년"]`
  4. `type:choice` · ruleNo `10` · "줄이 꽉 찼는데 마침표를 찍어야 해요. 바른 모습은?" · opts `[{n:7,rows:["해법은 달라요","!."]},{n:7,rows:["해법은 달라!{요.}"]}]` · a `1`
  - 각 문항의 `why`, `ruleName`은 해당 규정 카드의 내용으로 자연스럽게 채운다.

## 검증

- `python -c "import json; d=json.load(open('app/tutorial/content/elem/course1.json',encoding='utf-8')); print(len(d['lessons'][0]['cards']), len(d['lessons'][0]['questions']))"` → `4 4`
- 모든 원고지 `rows` 문자열이 표기법을 그대로 보존하는지(특히 `{ }`, `!`, `#`) 눈으로 확인한다.
- JSON은 `ensure_ascii=false`로 한글이 그대로 보이게 저장한다.
