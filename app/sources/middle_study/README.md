# 공부력 레벨 테스트 — 이식 패키지

8개 평가요소로 공부력 총점 200점을 산출하고 20점 구간으로 LV1~9를 판정한다.
학생용과 학부모용이 있으며, **학부모 응답은 레벨을 산출하지 않는다.**

| 파일 | 내용 |
|---|---|
| `items.json` | 문항 은행 (`mid` 52문항 / `elem` 33문항) |
| `content.json` | 평가요소, 레벨 구간표, 척도, 기준선, 학부모 관찰 영역 |
| `scoring.py` | 문항 배열 + 채점 엔진 (의존성 없음) |

---

## 1. 채점식

```
문항점수 = 배점 × (응답 − 1) / 4          정문항
         = 배점 × (5 − 응답) / 4          역문항 (rev: 1)

평가요소 점수 = 해당 요소 문항점수 합
평가요소 만점 = 해당 요소 배점 합
총점 = round(요소점수합 / 요소만점합 × 200)
```

| 폼 | 요소 | 요소당 문항 | 요소 만점 | 총점 만점 |
|---|---|---|---|---|
| `mid` (중등) | 8 | 6 | 25 | **200** |
| `elem` (초등 5~6) | 5 | 6 | 40 | **200** |

배점은 문항 난이도 가중이다. 중등은 `2·3·4·5·5·6`, 초등은 `4·6·7·7·8·8`.
**역문항은 배점 2점(초등 4점)과 5점(초등 7점) 자리에 하나씩** 들어가 있어
역문항 배점 비중이 모든 요소에서 정확히 28%다.

## 2. 레벨 구간

```
LV = min(9, max(1, 총점 // 20))
```

| 레벨 | 구간 | 명칭 | 코칭그룹 | 대응 성적대 |
|---|---|---|---|---|
| LV9 | 180~200 | 공부 마스터 | G1 | 최상위권 |
| LV8 | 160~180 | 자기 점검 | G2 | 상위권 |
| LV7 | 140~160 | 실행 지속 | G2 | 중상위권 |
| LV6 | 120~140 | 계획 수립 | G3 | 중상위권 |
| LV5 | 100~120 | 현실 인식 | G3 | 중위권 |
| LV4 | 80~100 | 과제 소화 | G4 | 중위권 |
| LV3 | 60~80 | 따라가기 | G4 | 하위권 |
| LV2 | 40~60 | 기초 쌓기 | G4 | 하위권 |
| LV1 | 20~40 | 출발선 | G4 | 하위권 |

## 3. 평가요소

### 중등 8요소
`MOT` 공부동기 · `BAS` 공부기초체력 · `RES` 공부책임감 · `REA` 공부현실감 ·
`PLN` 계획력 · `EXE` 실행력 · `OBJ` 객관화 · `FLW` 몰입

### 초등 5요소 (중등 대응)
| 키 | 이름 | 중등 대응 |
|---|---|---|
| `MOT` | 공부 동기 | 공부동기 |
| `BAS` | 공부 기초 | 공부기초체력 |
| `ATT` | 공부 태도 | 공부책임감 + 지구력 |
| `SLF` | 자기 관리 | 계획력 + 실행력 |
| `MET` | 돌아보는 힘 | 객관화 + 몰입 |

초등을 5로 묶은 이유: 요소당 4문항에 그중 하나가 역문항이면 실질 3문항이라
내적 일관성을 확보하기 어렵고, 초등 5학년이 계획력과 실행력을 구분해 답하기도 어렵다.

## 4. 척도 3종

| 키 | 라벨 | 쓰는 곳 |
|---|---|---|
| `agree` | 전혀 아니다 / 아니다 / 보통 / 그렇다 / 매우 그렇다 | 태도·신념 |
| `freq` | 전혀 없다 / 드물게 / 가끔 / 자주 / 거의 매번 | 행동 빈도 |
| `days` | 0일 / 1~2일 / 3~4일 / 5~6일 / 매일 | 지난 한 주 실행 |

문항에 `"lead": 1` 이 있으면 `"지난 한 주 동안, "`, `2` 면 `"최근 한 달 동안, "` 을
본문 앞에 붙인다 (`content.json` → `lead`). **채점식은 세 척도가 모두 같다.**
척도를 나눈 목적은 자기 관대성 차단이다. "하루 단위 계획을 세운다"에 4점 주기는
쉽지만 "지난 한 주 동안 계획을 정한 날"에 5~6일을 고르기는 어렵다.

## 5. 문항 배열 — `arrange()`

같은 요소 문항이 이어붙으면 학생이 앞 답에 맞춰 뒤를 고른다. 요소 내 상관이
인위적으로 올라가 신뢰도가 실제보다 높아 보이고 변별력은 떨어진다.

`arrange()` 는 요소를 돌아가며 한 문항씩 뽑고 매 바퀴 시작 요소를 한 칸씩 민다.
부풀림 문항(`e: "V"`)은 마지막에 고르게 끼워 넣는다.
**무작위가 아니라 고정 순서**라 학생 간 비교가 유지된다.

결과: 같은 요소 인접 0건. 부풀림 문항 위치 중등 10·21·33·44, 초등 8·17·27.

> JS 구현(`study-level.html`)과 Python 구현이 동일한 순서를 낸다. 검증 완료.

## 6. 학부모 폼

`build_form(grade, "parent", …)` 는 관찰 가능한 영역만 출제한다.

| 폼 | 출제 영역 | 문항 수 |
|---|---|---|
| `mid` | BAS · RES · PLN · EXE | 26 |
| `elem` | BAS · ATT · SLF | 20 |

동기·현실감·객관화·몰입은 부모가 관찰할 수 없는 내면이라 제외했다.
**학부모 응답에는 `level` 이 `None` 으로 나온다.** 영역 일부만 재고 총점을 내면
그 숫자는 의미가 없다. 인식 격차 표도 공통 영역만 비교할 것.

문항 본문의 1인칭은 3인칭으로 바꿔 출력한다. 문항에 `"p"` 필드가 있으면
그것을 그대로 쓰고, 없으면 다음 규칙으로 변환한다 (JS `qText()` 참고).

```
"나는 " → 삭제      "내가 " → "자기가 "     "나만의 " → "자기만의 "
"내 "   → "자기 "   "나보다 " → "자기보다 "
그 뒤 "우리 아이는 " 을 앞에 붙인다. 단 "~한 날" / "~한 적" 으로 끝나면 "우리 아이가 ".
```

## 7. 채점 계약

```python
from scoring import load, build_form, score, level_info

items_json, content = load()
form   = build_form("mid", "student", items_json, content)
result = score(answers, form, "student")     # answers: [1~5, …]
level  = level_info(result["level"], content)
```

### 출력
```jsonc
{
  "respondent": "student",
  "elements": [ { "key":"MOT", "name":"공부 동기", "area":"학습동기", "group":"G4",
                  "raw":18.5, "max":25, "score":74.0, "gate":50, "pass":true }, … ],
  "total": 150, "raw_total": 150.0, "raw_max": 200,

  "weak_index": 4, "weak_key": "REA",
  "flags": { "inflate": false, "inflate_count": 0, "validity_items": 4,
             "flat": false, "sd": 0.94, "topheavy": false }
}
```

## 8. 응답 신뢰도 3중 장치

| 장치 | 조건 | 처리 |
|---|---|---|
| **부풀림** | 부풀림 문항 중 '매우 그렇다'(5) 응답 ≥ 2개 | 경고 표시, 점수는 유지 |
| **무성의** | **원응답값** 표준편차 < 0.55 | **레벨 미산출**, 재검사 안내 |
| **역피라미드** | 상위영역 평균 − 하위영역 평균 ≥ 12 | 경고 표시 |

> ⚠️ 무성의 판정은 반드시 **원응답값**으로 계산한다. 역문항 보정값으로 계산하면
> 판정이 뒤집힌다. 전부 5점을 찍은 무성의 응답이 보정 후 5/1 로 벌어져 통과하고,
> 역문항을 제대로 구분한 성실한 응답(4/2)이 보정 후 전부 4가 되어 걸린다.
> 초기 구현에 이 버그가 있었고 v1.0에서 수정했다.

검증 (중등 폼)

| 응답 패턴 | 총점 | 판정 |
|---|---|---|
| 전부 5점 | 144 | 레벨 미산출 + 부풀림 |
| 전부 3점 | 100 | 레벨 미산출 |
| 역문항 구분 4/2 | 150 | LV7 실행 지속 |
| 정답형(긍정5·역1) | 200 | LV9 공부 마스터 |

역문항 28% 덕분에 straight-lining으로는 LV9에 닿을 수 없다.

## 9. Flask 연동 예시

```python
from tests.study_level.scoring import load, build_form, score, level_info

_ITEMS, _CONTENT = load()
_FORMS = { (g, w): build_form(g, w, _ITEMS, _CONTENT)
           for g in ("mid", "elem") for w in ("student", "parent") }

@bp.get("/form")
def get_form():
    f = _FORMS[(request.args["grade"], request.args["respondent"])]
    lead = _CONTENT["lead"]
    return jsonify({
        "elements": [e["n"] for e in f["elements"]],
        "items": [{ "text": lead.get(str(q.get("lead")), "") + q["t"],
                    "scale": _CONTENT["scales"][q.get("s", "agree")] } for q in f["items"]]
    })   # 요소 키·배점·역문항 여부는 클라이언트로 보내지 않는다

@bp.post("/submit")
def submit():
    b = request.get_json()
    f = _FORMS[(b["grade"], b["respondent"])]
    r = score(b["answers"], f, b["respondent"])
    save_attempt(b["student_id"], b, r)
    return jsonify({ "result": r, "level": level_info(r["level"], _CONTENT) })
```

## 10. 저장 스키마 제안

```sql
CREATE TABLE study_level_attempt (
  id          BIGSERIAL PRIMARY KEY,
  student_id  BIGINT NOT NULL,
  grade       TEXT   NOT NULL,   -- mid | elem
  respondent  TEXT   NOT NULL,   -- student | parent
  taken_at    DATE   NOT NULL,
  answers     JSONB  NOT NULL,
  total       INT    NOT NULL,
  level       INT,               -- 학부모 폼·무성의 응답이면 NULL
  elements    JSONB  NOT NULL,
  flags       JSONB  NOT NULL,
  engine_ver  TEXT   NOT NULL    -- 'sl-1.0'
);
```

인식 격차는 같은 `student_id` 의 최신 `student` 행과 최신 `parent` 행에서
**공통 영역만** 골라 `score` 차이를 낸다. 15점 이상 벌어진 항목이 상담 출발점이다.

## 11. 조정 가능한 상수

| 상수 | 현재값 | 의미 |
|---|---|---|
| `INFLATE_MIN` | 2 | 부풀림 경고 기준 (5점 응답 개수) |
| `FLAT_SD` | 0.55 | 무성의 판정 표준편차 |
| `TOPHEAVY_GAP` | 12 | 역피라미드 경고 기준 |
| `content.gates.mid` | `[50,52,54,56,58,60,62,64]` | 영역별 참고 기준선 |
| `content.gates.elem` | `[50,54,57,60,63]` | 〃 |

기준선은 레벨 산출에 쓰이지 않는다. 같은 레벨 안에서 무엇부터 손댈지 고르는
**보조 지표**다. 아래 영역일수록 낮게 둔 이유는 토대는 대부분의 학생이 어느 정도
갖추고 있고 위로 갈수록 갖춘 학생이 줄기 때문이다.

## 12. 남은 작업

- **배점 사다리 재배정** — `2·3·4·5·5·6` 이 실제 동의 난이도와 맞는지 미확인.
  파일럿 30~50명의 문항별 평균 응답값을 내림차순 정렬해 배점을 재배정하면 된다.
  문항을 새로 쓸 필요가 없어 비용 대비 효과가 가장 크다.
- **요소 간 중복 제거** — 상관 0.8 초과 쌍이 나오면 문항 교체 또는 요소 통합.
- **성적 입력 연동** — `BAS` 는 자기보고라 실제 성적과 가장 자주 어긋난다.
- **학년별 구간 경계 점검** — 중1과 중3에 같은 구간표를 쓰는 것이 맞는지.

## 13. 저작권

참고자료(브릿지교육컨설팅 「공부자아&공부력 평가등급 설명자료」, 「공부력 리포트 및 테스트」)는
제3자 저작물이며 무단복사·배포 금지 표시가 있다. 따라서

- 원 56문항을 옮기지 않고 **전부 새로 작성**했다.
- 9단계 명칭(자유인·깜깜이·지각생·학원맨 등)을 쓰지 않고 **새로 지었다.**
- 평가요소 구성, 배점 차등 방식, 9단계 구간표, G1~G4 코칭그룹 같은 **구조는 그대로 따랐다.**
  아이디어와 체계는 표현이 아니므로 사용에 문제가 없다.

이 선을 유지할 것. 문항 문장과 명칭은 표현이라 그대로 쓰면 걸리고,
요소 구성과 채점 체계는 아이디어라 괜찮다.
